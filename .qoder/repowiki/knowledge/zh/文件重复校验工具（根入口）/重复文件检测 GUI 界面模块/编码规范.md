- 每个标签页实现为独立类（如 `ExactMatchTab`、`SimilarityTab`），在 `__init__` 中接收 `parent_notebook` 和 `main_window` 引用，并创建 `self.frame = ttk.Frame(parent_notebook)` 作为容器。
- 标签页内部采用 `_create_widgets` 拆分布局方法，并按“设置区 → 控制按钮 → 进度区 → 日志区”的顺序依次调用子构造方法组装界面。
- 用户输入通过 `tk.StringVar` / `tk.IntVar` / `tk.BooleanVar` 等 Tkinter 变量绑定 Entry、Scale、Checkbutton 等控件，便于跨方法读取最新值。
- 进度与日志通过主窗口提供的 `update_progress(progress, message)`、`update_detail(message)`、`_log(message, level)` 回调更新，保持 UI 线程安全。
- 扫描任务在独立线程中执行，使用 `threading.Event` 作为 `stop_flag` 支持中途停止，并在 UI 上启用/禁用“开始/停止”按钮。
- 详情结果通过 `detail_window.py` 中的工厂函数（如 `create_exact_match_detail`、`create_image_similarity_detail`）统一弹出，避免在各标签页内重复实现详情窗口。

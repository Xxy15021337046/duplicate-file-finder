- 每个引擎类在 `__init__` 中初始化 SQLite 连接并设置 PRAGMA（WAL、synchronous=NORMAL、cache_size=-64000、temp_store=MEMORY、mmap_size=268435456）以提升大规模写入并发性能。
- 数据库操作统一通过 `_get_connection` 返回连接，并用 `_get_db_connection` 上下文管理器封装事务提交/回滚与连接关闭。
- 大量 I/O 或 CPU 密集型任务（哈希计算、关键帧提取、图片指纹）使用 `concurrent.futures` 的 `ThreadPoolExecutor` 或 `ProcessPoolExecutor` 并行处理，并通过 `as_completed` 收集结果。
- 进度与日志通过构造时注入的 `progress_callback(progress, message)` 与 `log_callback(message, level)` 回调上报，避免直接耦合 UI。
- 指纹/特征计算逻辑被抽成模块级全局函数（如 `_compute_image_fingerprint`、`_compute_video_fingerprint`），以便在多进程环境中安全序列化传递。
- 相似度判定普遍采用“快速筛选 → 二次验证 → 精确比对”的多级过滤策略（如图片的 pHash→dHash→直方图，视频的 pHash 匹配矩阵→对角线序列→Jaccard+时间覆盖率）。

根目录作为应用装配层：`run_gui.py` 是统一入口，通过 `sys.path.insert` 将项目根加入导入路径后实例化 `gui_modules.main_window.DuplicateFinderGUI`；GUI 层再调用 `core` 子模块提供的哈希/感知哈希/关键帧匹配等检测能力，并通过 SQLite 持久化索引结果。顶层的 `requirements.txt` 集中声明 core 与 gui 共同依赖的第三方库（Pillow、imagehash、opencv-python-headless、pefile、packaging、watchdog 等），`build.bat` / `build.sh` / `build_release.bat` 基于 `文件重复校验工具.spec` 使用 PyInstaller 将两者打包为单文件可执行程序，`start.bat` 用于本地快速启动。
